Temel Tanım

İşletim Sistemi Nedir?

İşletim sistemi, kullanıcı ile bilgisayar donanımı arasında aracı görevi gören bir programdır. Üç temel hedefi vardır:

🎯

Kullanıcı Programlarını Çalıştır

Kullanıcının problemlerini çözmeyi kolaylaştırmak için programları yükler ve yönetir.

🖥️

Kullanım Kolaylığı

Donanımın karmaşıklığını gizleyerek sistemin kullanımını kolaylaştırır.

⚡

Verimli Kaynak Kullanımı

CPU, bellek ve I/O gibi kaynakları adil ve verimli biçimde dağıtır.

💡

İki Kritik Tanım

  • Kaynak Yöneticisi (Resource Allocator): Tüm kaynakları yönetir; çakışan istekler arasında adil ve verimli kararlar alır.
  • Kontrol Programı (Control Program): Hataları ve yanlış kullanımı önlemek için program çalışmasını denetler.
  • Kernel: Bilgisayarda her zaman çalışan TEK programdır. Diğerleri sistem programı veya uygulama programıdır.

Boot

Bilgisayar Başlatma (Bootstrap)

Güç açıldığında veya yeniden başlatıldığında sistemi ayağa kaldıran süreç:

1. Bootstrap Program
Güç açılışında yüklenen ilk program. ROM veya EPROM'da (firmware) saklanır. Sistemin tüm yönlerini başlatır.
2. Kernel Yükleme
Bootstrap, OS kernel'ini bulur, belleğe yükler ve çalıştırmaya başlar.
3. Init / Systemd
Kernel başladıktan sonra sistem süreçlerini ve servislerini başlatır.
🔑

GRUB — Grand Unified Bootloader

Yaygın bootstrap loader; birden fazla disk, sürüm ve kernel seçeneği sunar. Linux sistemlerde önyükleme menüsünü siz görürsünüz.

Interrupt (Kesme) Mekanizması

İşletim sistemi interrupt-driven (kesme güdümlü) çalışır. Her interrupt kontrolü interrupt servis rutinine transfer eder.

Interrupt Vector
Tüm servis rutinlerinin adreslerini içeren tablo. Her interrupt türüne karşılık gelen ISR adresi burada.
Trap / Exception
Hata (sıfıra bölme) veya kullanıcı isteğinden (system call) kaynaklanan yazılım kesmesi.
DMA (Direct Memory Access)
Yüksek hızlı I/O için CPU müdahalesiz blok halinde bellek transferi. Her blok için 1 interrupt — her byte için değil. I/O verimliliği artar.
Polling
CPU, hangi cihazın interrupt oluşturduğunu sürekli sorgular. Basit ama verimsiz.
Bellek

Depolama Hiyerarşisi

Depolama sistemleri hız, maliyet ve kalıcılığa göre hiyerarşik düzenlenir. Bir seviyeye tıkla:

Depolama Piramidi (hıza göre yukarıdan aşağı)
⚡ Register ~0.3ns
🔥 Cache (L1/L2/L3) ~1-10ns
💾 Main Memory (RAM) ~100ns
💿 SSD (Flash) ~0.1ms
🖴 Hard Disk (HDD) ~5-10ms
📼 Optical / Tape saniyeler
Bir seviyeye tıkla → detay görün
💡

Caching İlkesi

  • Daha yavaş depolamadaki bilgi, geçici olarak daha hızlı depolamaya kopyalanır.
  • Cache daha küçüktür → cache yönetimi kritik: boyut ve replacement policy.
  • Cache Coherency: Çoklu CPU'da tüm önbelleklerin en güncel değeri tutması. Donanım garantisi gerektirir.
Güvenlik

Dual-Mode İşlem

OS kendini ve sistem bileşenlerini korumak için iki mod kullanır:

⚙️ Kernel Mode

  • OS kodu çalışır
  • Tüm talimatlar mevcut (ayrıcalıklı)
  • Mode bit = 0
  • System call ile geçiş yapılır

👤 User Mode

  • Kullanıcı kodu çalışır
  • Ayrıcalıklı talimatlar yasak
  • Mode bit = 1
  • System call çıkışında dönülür
⏰

Timer — Sonsuz Döngü Engeli

Donanım timer'ı, belirlenen süre sonra interrupt oluşturur. OS bu sayede CPU kontrolünü geri alır ve süresini aşan programları sonlandırır.

Multiprogramming vs Timesharing

Multiprogramming
Bir iş I/O beklerken başka bir iş CPU'da çalışır. CPU her zaman meşgul → verimlilik artar. Job scheduling gerektirir.
Timesharing (Multitasking)
CPU çok sık iş değiştirerek (ms bazında) her kullanıcıya etkileşimli deneyim verir. Yanıt süresi genellikle <1 saniyedir.
Virtual Memory
İşlemin tamamı bellekte olmadan çalıştırılabilir. Disk, ek bellek olarak kullanılır.
