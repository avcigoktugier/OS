4R Faydası

Thread'lerin 4 Temel Faydası

⚡

Responsiveness (Yanıt Verme)

Sürecin bir thread'i bloklanmış olsa bile diğer thread'ler çalışmaya devam eder. Kullanıcı arayüzü (UI) thread'leri için kritik.

🤝

Resource Sharing (Kaynak Paylaşımı)

Thread'ler sürecin kod, veri ve dosyalarını paylaşır. Shared memory veya IPC mekanizmasından çok daha kolay ve hızlı.

💰

Economy (Ekonomi)

Thread oluşturmak, süreç oluşturmaktan çok daha ucuzdur (bellek/zaman). Context switch overhead'i de daha azdır.

📈

Scalability (Ölçeklenebilirlik)

Çok çekirdekli (multicore) mimaride thread'ler gerçek anlamda paralel çalışabilir; tek çekirdekte mümkün olmayan performans elde edilir.

Parallelism

Çok Çekirdekli Programlama

Parallelism (Paralellik)
Fiziksel olarak aynı anda birden fazla iş yapılır. Çok çekirdekli donanım gerektirir. Örnek: 4 çekirdekte 4 thread eş zamanlı çalışır.
Concurrency (Eşzamanlılık)
Birden fazla iş ilerleme kaydeder, ancak aynı anda olmayabilir. Tek çekirdekte context switch ile sağlanır. Parallelism gerektirmez.
Data Parallelism
Aynı veri kümesinin farklı alt kümeleri, farklı çekirdeklerde aynı işlem uygulanır. Örnek: büyük dizinin yarısı çekirdek 1'de, diğer yarısı çekirdek 2'de.
Task Parallelism
Farklı thread'ler farklı işlemleri aynı veya farklı veri üzerinde yapar. Her thread farklı bir görevi gerçekleştirir.
📐

Amdahl Yasası

Speedup ≤ 1 / (S + (1−S)/N)

  • S = seri (paralelize edilemeyen) kısım oranı
  • N = çekirdek sayısı
  • Uygulama %75 paralel, %25 seri → 2 çekirdekte speedup = 1.6x
  • N → ∞ iken speedup → 1/S (üst sınır)
  • Öğretisi: Seri kısım ne kadar büyükse çok çekirdekten o kadar az faydalanılır.

Implicit Threading

Thread Pools
Başlangıçta belirli sayıda thread oluşturulur ve hazır bekletilir. İstek geldiğinde hazır thread alır → yeni oluşturmaktan hızlı. Thread sayısını sınırlar (sistem koruması). Java ThreadPoolExecutor, .NET ThreadPool
OpenMP
C/C++/Fortran için derleyici direktifleri. #pragma omp parallel ile paylaşımlı bellek paralelizmi. Döngüler otomatik paralel bölünür.
GCD — Grand Central Dispatch
Apple (macOS/iOS). ^{ } blok söz dizimi. Dispatch queue'lara (serial/concurrent) görevler gönderilir; sistem kaç thread kullanacağına karar verir.
Sorunlar

Thread Sorunları

Sorun Açıklama Çözüm / Not
fork() / exec() fork() tüm thread'leri kopyalar mı? İki sürüm: yalnız çağıran thread veya tüm thread'ler. exec() normalde tüm thread'leri değiştirir.
Signal Handling UNIX sinyali hangi thread'e gönderilir? Thread'e özel (SIGSEGV) veya tüm thread'lere. Uygulamada karmaşık; pthread_kill() ile yönlendirme.
Thread Cancellation Çalışan thread'i durdurmak Async: anında durdurur, kaynak riski. Deferred: cancellation point'te kontrollü bitiş.
Thread-Local Storage (TLS) Her thread'in kendi "global" verisi __thread (C), ThreadLocal (Java). Static değişken gibi ama thread'e özeldir.
